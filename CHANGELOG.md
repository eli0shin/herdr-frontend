## 0.1.3

### Patch Changes

- [#70](https://github.com/eli0shin/herdr-frontend/pull/70) [`f825c43`](https://github.com/eli0shin/herdr-frontend/commit/f825c4379127b3fb88afb9d7dbe94c068e9a9884) Thanks [@eli0shin](https://github.com/eli0shin)! - Neovim keeps herdr-frontend's grid with Herdr app open on the same core: a new pane's terminal starts at that pane's grid, and focusing a pane tells the program herdr-frontend's size again, so its first frame no longer comes out cut up and wrapped.

## 0.1.2

### Patch Changes

- [#63](https://github.com/eli0shin/herdr-frontend/pull/63) [`ce7f5d9`](https://github.com/eli0shin/herdr-frontend/commit/ce7f5d9641aa31ff96297e78618572c0a8093895) Thanks [@eli0shin](https://github.com/eli0shin)! - The app never writes its config folder (`~/.config/herdr-frontend`) any more, so `settings.json`, `keys.json`, themes and programs can live in dotfiles without diffs. Everything it writes now goes in `~/.local/state/herdr-frontend`: the window's place, the view, the sidebar's shared state, the Agents list's times, `keys.error`, the control socket, and the zoom. The zoom keys no longer change `settings.json`. Its `zoom` is the starting value, and editing it still changes the zoom. State files left in the config folder by older versions are moved over at the first launch.

- [#54](https://github.com/eli0shin/herdr-frontend/pull/54) [`efc7e6d`](https://github.com/eli0shin/herdr-frontend/commit/efc7e6d2868f33e6222eff5f9f41892573ac0b4a) Thanks [@eli0shin](https://github.com/eli0shin)! - Terminal text stays on its cells at every zoom. When zoomed (1.1 by default), each glyph sat a fraction of a pixel further off its column than the last. By the end of a long line the cursor, the selection and copy mode's cursor covered the wrong letters, and text crowded the Nerd Font icons beside it. Each glyph now sits on its own cell across the whole line, under the cursor and selection that mark it.

- [#62](https://github.com/eli0shin/herdr-frontend/pull/62) [`ca8be95`](https://github.com/eli0shin/herdr-frontend/commit/ca8be95672243b3389a97a855b13d43d97296aad) Thanks [@eli0shin](https://github.com/eli0shin)! - No more animations. Every change now shows in the frame that draws it: the sidebar opening and closing, panes splitting and resizing, popups, menus and the palette opening and closing, the palette's list moving, toasts, selections and hover highlights, and a mouse wheel's notch scrolling the sidebar, a popup list, the keys help or the tab strip. The only motion left is the working spinner, and every spinner on screen now points the same way at the same moment, as in Herdr app.

- [#58](https://github.com/eli0shin/herdr-frontend/pull/58) [`dc76e5e`](https://github.com/eli0shin/herdr-frontend/commit/dc76e5e5605c2c753a772f5a214ba98f854ad80f) Thanks [@eli0shin](https://github.com/eli0shin)! - In the Agents list, an orchestrator's colored left border follows the section it sits in: an idle orchestrator lifted to Working by a working worker gets the working border, and the same holds for Needs you and Done. Workers nested under an orchestrator have no border; their spinner or dot stays. Other rows are unchanged.

- [#56](https://github.com/eli0shin/herdr-frontend/pull/56) [`3730fa8`](https://github.com/eli0shin/herdr-frontend/commit/3730fa867eb3da95161cf5b95639812241591fad) Thanks [@eli0shin](https://github.com/eli0shin)! - The sidebar and chrome text draws in Operator Mono Medium, which gives it the weight of Herdr app's labels (Herdr app thickens its Book face with font smoothing). Terminals stay in Book. Tab pills and Agents rows are now as wide and tall as Herdr app's at the same zoom. Program icons in the Agents list, the PR finder and the peek take the program's color, as the tab bar's do, so Pi's is purple.

- [#60](https://github.com/eli0shin/herdr-frontend/pull/60) [`dc31c26`](https://github.com/eli0shin/herdr-frontend/commit/dc31c261355ad9d1ac9baa9d2fc8a0efb4ad53e3) Thanks [@eli0shin](https://github.com/eli0shin)! - Every pane shown in the window in front now keeps its terminal at the pane's size, not just the focused one. After a split, a close, a divider drag, a sidebar toggle, a window resize or a zoom, each pane redraws at its new size at once, without a click. Split panes are sized in whole terminal cells, so each terminal's grid reaches the divider. Divider drags snap to cell boundaries, and the resize keys (`alt-shift-h/j/k/l`) move a divider 5 columns across or 2 rows down per press. A grid that doesn't fill its pane's height sits at the pane's bottom, with the leftover above it. Space a pane hasn't filled yet shows the terminal's background, not the grey split-gap color.

- [#55](https://github.com/eli0shin/herdr-frontend/pull/55) [`a647043`](https://github.com/eli0shin/herdr-frontend/commit/a6470430cbecb1c75f00351811f7da4b7a3c8f7f) Thanks [@eli0shin](https://github.com/eli0shin)! - Popup lists (the command palette, the pickers, the settings and machine dialogs) are one flat list that the mouse wheel and trackpad scroll, leaving the selection where it is. A list that fits doesn't scroll, and the palette keeps its height as you move through it. Key hints in the palette, menus and keys help show your prefix key when a command has one (`ctrl-g t` for New tab, `ctrl-g shift-q` for Close tab), and another key only when it has none. The palette no longer offers "Reset to the default keys", and the tab strip no longer shows a `ctrl-g …` indicator while a prefix is pending.

- [#64](https://github.com/eli0shin/herdr-frontend/pull/64) [`b5b7860`](https://github.com/eli0shin/herdr-frontend/commit/b5b7860044777ccdfd8250ab5e758008cdfa6a3d) Thanks [@eli0shin](https://github.com/eli0shin)! - A program that redraws when its pane changes size (Pi, Neovim without in-band size reports, any full-screen program) no longer ends up torn, wrapped or shifted after the sidebar closes, a zoom, a window resize or a new pane taking its size. A shown pane now resizes its terminal as it sends its new size, so the program's redraw is read at the right grid.

- [#65](https://github.com/eli0shin/herdr-frontend/pull/65) [`a7b735b`](https://github.com/eli0shin/herdr-frontend/commit/a7b735b9a8e4463364400a44686b6c568e6f2bd6) Thanks [@eli0shin](https://github.com/eli0shin)! - A trackpad (and its momentum) or a free-spinning wheel scrolls a terminal's scrollback smoothly, by the pixel, instead of a line at a time. Distances are the same as before and the same as Herdr app's: a line per cell height of travel, times `terminal_scroll_speed`. The screen moves in the frame the scroll arrives, rather than after the terminal's worker answers. A notched mouse wheel still moves three whole lines a notch, and programs that track the mouse still get whole wheel events.

- [#57](https://github.com/eli0shin/herdr-frontend/pull/57) [`9242760`](https://github.com/eli0shin/herdr-frontend/commit/924276092be1cd69a2a7e794231f7acbc8ef9edb) Thanks [@eli0shin](https://github.com/eli0shin)! - The window no longer fights a tiling window manager. It saves its size and position only when it closes or quits, not on every resize, so it no longer records the corner AeroSpace parks hidden windows in or a frame AeroSpace gave it, and a saved place that's mostly off every display reopens centered. It never reopens zoomed or full screen. A double click on the tab strip or the sidebar's top row no longer zooms the window over the whole display and under AeroSpace's bar. Resizing no longer briefly gives the borderless window a title bar on every size change, which used up about half the UI thread while AeroSpace resized it.
