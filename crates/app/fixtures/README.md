# Fixture screens

Program output the renderer's scenes, headless tests and Ghostty pixel diff draw
(`src/fixtures.rs`). Each is the bytes a program wrote to an 80 × 30 terminal.

- `colors.bin`, `boxes.bin`: generated by `python3 -I make.py`.
- `nvim-splits.bin`: Neovim 0.12.6 with three splits, line numbers, a cursorline and a visual
  selection, recorded with the terminal tests' recorder:

  ```sh
  cd crates/terminal/tests/streams
  python3 -I record.py ../../../app/fixtures/nvim-splits.bin 80 30 -- \
      nvim --clean --cmd 'set termguicolors' meters.py < steps
  ```

  where `steps` is:

  ```text
  sleep 1.5
  send ":set number cursorline\r"
  sleep 0.5
  send ":vsplit sample.txt\r"
  sleep 0.5
  send ":split pager.txt\r"
  sleep 0.5
  send ":set number\r"
  sleep 0.5
  send "\x17l"
  sleep 0.5
  send "9G"
  sleep 0.5
  send "vjj$"
  sleep 1
  ```

`scripts/ghostty-diff` doesn't replay these files into Ghostty: Ghostty's window is whatever size
the window manager gives it, so it runs the same programs live at Ghostty's grid and records what
they write, and the renderer draws that recording at the same grid.
