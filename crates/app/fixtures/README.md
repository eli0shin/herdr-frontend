# Fixture screens

Program output the renderer's scenes, headless tests and Ghostty pixel diff draw
(`src/fixtures.rs`). Each is the bytes a program wrote to an 80 × 30 terminal.

- `colors.bin`, `boxes.bin`, `styles.bin`: generated by `python3 -I make.py`. `styles.bin` is the
  same lines in regular, bold, italic and bold italic, which `scripts/ghostty-diff styles` draws in
  Operator Mono Book at 18.7 pt: Ghostty with `styles.ghostty`, herdr-frontend with
  `styles.json`, the same font settings in each one's terms.
- `nvim-splits.bin`: Neovim 0.12.6 with three splits, line numbers, a cursorline and a visual
  selection, recorded with the terminal tests' recorder:

  ```sh
  cd crates/terminal/tests/streams
  python3 -I record.py ../../../app/fixtures/nvim-splits.bin 80 30 -- \
      nvim --clean --cmd 'set termguicolors' meters.py < steps
  ```

  where `steps` is:

  ```text
  sleep 1.5
  send ":set number cursorline\r"
  sleep 0.5
  send ":vsplit sample.txt\r"
  sleep 0.5
  send ":split pager.txt\r"
  sleep 0.5
  send ":set number\r"
  sleep 0.5
  send "\x17l"
  sleep 0.5
  send "9G"
  sleep 0.5
  send "vjj$"
  sleep 1
  ```

- `nvim-checklist.bin`: Neovim 0.12.6 with `nvim-checklist.lua`: splits, a float with a rounded
  border, undercurled and underdotted diagnostics in their colors, a statusline with Nerd Font
  icons and Powerline separators, CJK and emoji, and `:%s/nam/name` typed into the cmdline.
  Neovim sends undercurls only to a terminal whose terminfo has them, so it runs with Ghostty's:

  ```sh
  cd crates/terminal/tests/streams
  printf 'sleep 2\nsend ":%%s/nam/name"\nsleep 1\n' >steps
  python3 -I record.py ../../../app/fixtures/nvim-checklist.bin 80 30 -- /usr/bin/env \
      TERM=xterm-ghostty TERMINFO=/Applications/Ghostty.app/Contents/Resources/terminfo \
      nvim -n -i NONE -u "$PWD/../../../app/fixtures/nvim-checklist.lua" < steps
  ```

`scripts/ghostty-diff` doesn't replay these files into Ghostty: Ghostty's window is whatever size
the window manager gives it, so it runs the same programs live at Ghostty's grid and records what
they write, and the renderer draws that recording at the same grid.
